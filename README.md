# Тестовое задание: подготовка золотого слоя данных

## 1. Описание

Необходимо разработать программу для автоматизированной загрузки и обработки статистических данных о заработной плате работников сферы образования.

Исходные данные представлены в виде файлов Excel (`.xlsx`), опубликованных в открытом доступе.

Файлы содержат статистические данные по субъектам Российской Федерации за различные периоды.

Пример исходного файла:

> Средняя заработная плата педагогических работников дошкольных образовательных организаций государственной и муниципальной форм собственности по субъектам Российской Федерации за январь-июнь 2023 года.

Исходные Excel-файлы имеют сложную структуру и не предназначены для непосредственного использования в аналитических системах: заголовки занимают несколько строк, присутствуют объединённые ячейки, вложенные показатели, пропуски и служебные обозначения.

Необходимо преобразовать исходные данные в структурированный набор данных, пригодный для дальнейшего анализа.

Основной результат задания — **золотая таблица (`gold layer`)**.

# 5. Загрузка данных

Необходимо реализовать функцию загрузки исходного файла.

Функция должна:

1. Получать URL исходного файла.
    
2. Загружать файл.
    
3. Сохранять его локально.
    
4. Проверять успешность загрузки.
    
5. Не загружать файл повторно, если файл уже существует и не требуется его обновление.
    

Необходимо предусмотреть обработку ошибок загрузки.

Например:

- HTTP 404;
    
- HTTP 500;
    
- отсутствие соединения;
    
- некорректный URL;
    
- недоступность файла.
    

Конкретная реализация остаётся на усмотрение кандидата.

# 6. Обработка Excel-файлов

После загрузки необходимо обработать полученные `.xlsx`-файлы.

Исходные Excel-файлы имеют сложную структуру.

Например:

```text
Средняя заработная плата ...
        │
        ├── всего
        │
        └── в том числе по формам собственности организаций
                ├── федеральная
                ├── субъектов РФ
                └── муниципальная
```

Заголовок таблицы может занимать несколько строк и содержать объединённые ячейки.

Необходимо самостоятельно определить структуру исходного файла и преобразовать её в табличный формат.

Решение не должно быть жёстко привязано к конкретному номеру строки заголовка.

Например, решение вида:

```python
pd.read_excel(file, header=4)
```

без дополнительной обработки структуры файла не считается достаточным.


# 8. Определение региона

В исходных данных присутствуют:

- Российская Федерация;
    
- федеральные округа;
    
- субъекты Российской Федерации.
    

Например:

```text
Российская Федерация

Центральный федеральный округ
    Белгородская область
    Воронежская область
    ...

Северо-Западный федеральный округ
    ...
```

Необходимо определить принадлежность каждого субъекта РФ к федеральному округу.

В итоговой таблице должны присутствовать как минимум:

```text
region
federal_district
```

Например:

|region|federal_district|
|---|---|
|Белгородская область|Центральный федеральный округ|
|Воронежская область|Центральный федеральный округ|
|Республика Карелия|Северо-Западный федеральный округ|

Строки федеральных округов и `Российская Федерация` не должны ошибочно рассматриваться как субъекты РФ.

# 10. Формирование золотой таблицы

Основным результатом задания является формирование **золотой таблицы**:

```text
gold_salary
```

Золотая таблица должна содержать подготовленные и проверенные данные, пригодные для дальнейшего использования в аналитических системах.

## Гранулярность

Необходимо самостоятельно определить и обосновать гранулярность итоговой таблицы.

Ожидается, что одна запись будет однозначно описывать данные:

> одного субъекта РФ за один период по одному набору показателей.

Возможный ключ:

```text
region + year + period
```

Однако кандидат должен самостоятельно подтвердить выбранную гранулярность и ключ на основании анализа исходных данных.

# 11. Состав золотой таблицы

Состав итоговой таблицы кандидат определяет самостоятельно.

В таблице должны присутствовать как минимум:

### Идентификация

```text
region
federal_district
year
period
```

### Показатели заработной платы

Необходимо сохранить показатели, содержащиеся в исходных файлах, в том числе показатели по формам собственности организаций, если они присутствуют в источнике.

Например:

```text
salary_total
salary_federal
salary_regional
salary_municipal
```

### Относительные показатели

Например:

```text
ratio_total
ratio_federal
ratio_regional
ratio_municipal
```

### Справочные показатели

Например:

```text
reference_salary
```

Названия колонок можно выбрать самостоятельно.

Они должны быть:

- понятными;
    
- единообразными;
    
- написанными в одном стиле;
    
- пригодными для использования в SQL и BI-системах.

# 14. Контроль качества данных

После формирования `gold_salary` необходимо выполнить проверки качества.

Минимально необходимо проверить:

### Уникальность

Ключ золотой таблицы должен быть уникальным.

### Обязательные поля

Как минимум:

```text
region
year
period
```

не должны быть пустыми.

### Числовые показатели

Поля с заработной платой должны иметь числовой тип.

### Относительные показатели

Относительные показатели должны иметь корректный числовой тип и находиться в разумном диапазоне.

### Период

Год и период должны соответствовать исходному файлу.

### Регионы

Необходимо проверить, что при обработке не произошла существенная потеря субъектов Российской Федерации.

Необходимо:

1. обнаружить проблему;
    
2. определить способ её обработки;
    
3. сохранить информацию о проблеме либо вывести её в отчёт;
    
4. описать принятое решение.
    

Например:

```text
Проблемы качества данных:

- 2 строки содержат некорректное числовое значение;
- 1 дубликат обнаружен в исходном файле.
```

Конкретный формат отчёта определяется кандидатом.
